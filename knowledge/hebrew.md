# Ancient Hebrew — Pictographic Chain

## System
- 22 letters, each with 4 characteristics: form + meaning + name + sound.
- Evolution chain: Pictographic → Phoenician → Greek → Latin → Modern.

## Pictographic Letter Chain
- aleph (ox / A), beth (tent / B), gimel (camel / G), dalet (door / D),
  heh (window / H), waw (nail / W,V), zayin (weapon / Z), chet (fence / Ch),
  tet (basket / T), yod (arm / Y), kaph (palm / K), lamed (staff / L),
  mem (water / M), nun (fish / N), samekh (thorn / S), ayin (eye / O),
  peh (mouth / P), tsade (trail / Ts), qoph (head / Q), resh (head / R),
  shin (teeth / Sh), taw (mark / T).

## Tetragrammaton
- YHWH (יהוה) root yhw = "to be". Part of the cross-religious divine name chain (see divine-names.md).

## Working Guidance
- Always provide the four-characteristic table (form/meaning/name/sound) for each glyph before translation.
- Specify the stage of the chain (Pictographic vs Paleo-Hebrew vs Square Hebrew).
- Do not over-assign pictographic meanings to post-Pictographic attestations.
