# Methodology — 10-Step Decipherment Protocol

## The Protocol
1. **Frequency analysis** — dominant sign = grammatical marker.
2. **Positional analysis (S/M/E)** — consistent positions = suffix/prefix/marker.
3. **Pictographic anchor** — signs resembling objects = semantic anchors.
4. **Rebus/homophone** — e.g. fish sign for STAR (mīn = fish = star in Dravidian).
5. **Bilingual Rosetta method** — the most powerful decipherment tool.
6. **Index of Coincidence (IC)** — random ≈ 0.038, English ≈ 0.067, Enochian ≈ 0.082. A value BELOW 0.038 is anomalous (see Voynich paradox).
7. **Zipf-Mandelbrot law** — all natural languages obey it; log-log plot of rank vs frequency ≈ straight line.
8. **Ventris grid technique** — consonant×vowel matrix; cracked Linear B in 1952.
9. **K-means clustering + PCA** — group signs by visual/phonetic features.
10. **Cross-script parallel** — apply known script patterns to unknown systems.
