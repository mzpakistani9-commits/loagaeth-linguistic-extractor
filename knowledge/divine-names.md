# Cross-Religious Divine Name Chain

## The Cognate Chain
- IAD (Enochian) → YHWH יְהוָה (Hebrew, root yhw = "to be")
- → ALLAH الله (Arabic, al + ilah) → ALAHA ܐܠܗܐ (Aramaic/Syriac)
- → THEOS ΘΕΟΣ (Greek, PIE dheu- "shine/blow") → DEVA देव (Sanskrit, PIE dyeu- "sky/shine")
- → KADAVUL கடவுள் (Tamil) → AN 𒀭 (Sumerian).

## Methodology
- Compare STRUCTURALLY similar divine names across traditions (consonantal skeleton, semantic domain, phonetic drift).
- Distinguish true cognates (shared historical origin) from structural parallels (coincidental or typological convergence) — label each explicitly.
- Sacred Text mode: cite each tradition's own canon for the name's function and epithets.
- Do not force equivalence where philology doesn't support it.

## Key Divinity Terms by Tradition
- Enochian: IAD, ALLA; Hebrew: ELOHIM, YAHWEH, ADONAI; Arabic: ALLAH, AR-RAHMAN;
  Aramaic: ALAHA, MAR; Greek: THEOS, KYRIOS; Sanskrit: DEVA, BRAHMA; Tamil: KADAVUL, IRAIVAN; Sumerian: AN, ENLIL, ENKI.
