# Undeciphered Ancient Scripts — Status Notes (2026)

## Linear A (Minoan)
- Minoan Crete, c. 1800–1450 BCE. ~1,400 inscriptions, ~90 signs (many overlap Linear B).
- Ventris grid technique possible but no bilingual; language family unknown (Minoan isolate hypothesis).
- Sign inventory shared with Linear B (which IS deciphered) — reuse B phonetic values only as POSSIBLE.

## Proto-Elamite
- Iran, c. 3100–2900 BCE. ~1,600 texts. Numerical/accounting core readable, linguistic layer not.

## Rongorongo (Easter Island)
- Extraordinary: 25+ wooden tablets, undeciphered. Glyphs ~120; direction bustrophedon+rotating (lunar/etta). No bilingual.

## Phaistos Disc
- Single object, both sides stamped spirals, 45 distinct glyphs, 241 impressions. Believed not genuine writing by most; origin/provenance uncertain.

## Meroitic
- Sudan, Kush, 300 BCE–400 CE. Deciphered alphabet but language isolate; signs readable, meaning largely unknown.

## Rohonc Codex
- ~450 pages, 448 distinct glyphs, unknown language and provenance (Hungary?), 19th c. claims of a cipher. Authenticity debated.

## Proto-Sinaitic & Wadi el-Hol
- Candidate earliest alphabetic scripts (c. 1900–1700 BCE). Wadi el-Hol graffiti glyphs partially overlap later Semitic values.

## Byblos Syllabary
- Byblos, c. 1700 BCE. Pseudohieroglyphic lines; undeciphered.

## Working Guidance
- Report status faithfully; mark EVERY unsupported reading [UNDECIPHERED].
- Use Ventris grid, IC/Zipf, positional analysis to produce testable hypotheses.
- Never present AI guesses as translation.
- Keep updates as of 2026 — no breakthrough bilingual has surfaced for any of these.
